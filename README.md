# Sistema Tienda

Repositorio para el manejo del inventario y las promociones de la tienda.

## Descripción

Este proyecto centraliza la información básica de la tienda, incluyendo:

- Listado de productos disponibles con su precio.
- Promociones y descuentos vigentes sobre esos productos.

## Contenido del repositorio

- `inventario.txt`: archivo con el listado de productos y precios, junto con la sección de promociones activas.

## Control de versiones

El historial de cambios se maneja mediante commits descriptivos:

- **inventario base**: versión inicial con el listado de productos y precios.
- **correccion**: actualizaciones posteriores, como la incorporación de promociones.
